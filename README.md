# Hello OSS

## 1. Giới thiệu

Hello OSS là một dự án mã nguồn mở đơn giản được xây dựng bằng ngôn ngữ C.

## 2. Mục tiêu

Dự án được tạo nhằm thực hành cách xây dựng tài liệu cho một dự án mã nguồn mở, bao gồm README, CONTRIBUTING và LICENSE.

## 3. Yêu cầu

* Git
* Trình biên dịch C như GCC

## 4. Cài đặt

Clone repository:

```bash
git clone https://github.com/<username>/hello-oss-doc.git
cd hello-oss-doc
```

## 5. Build

Sử dụng GCC:

```bash
gcc main.c -o hello-oss
```

## 6. Chạy chương trình

Trên Windows:

```bash
hello-oss.exe
```

Trên Linux/macOS:

```bash
./hello-oss
```

Kết quả:

```text
Hello OSS
```
